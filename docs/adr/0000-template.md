# NNNN. Short title in the imperative

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Supersedes:** —
- **Superseded by:** —

## Context

What is true that forces a decision. Constraints, volumes, failure modes, and
anything already decided that limits the options. Written so that someone who
was not there can tell whether the reasoning still holds.

## Decision

What is being done, stated plainly enough to be checkable in code review.

## Consequences

What this buys, and what it costs. The cost section is not optional — every
decision has one, and an ADR that lists only benefits is advocacy.

## Alternatives considered

Each rejected option with the reason it lost. "We did not think of it" is a
valid entry if honest; "it was worse" without a reason is not.
